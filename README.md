# 필기본 뷰어

https://chamcham02.github.io/notes_hangjeong/

이 저장소에는 **필기 내용이 없습니다.** 비공개 저장소에 있는 필기본 HTML을 GitHub 토큰으로 불러와 여는 작은 페이지(`index.html`)만 있습니다.

- 기기마다 처음 한 번 fine-grained 토큰(대상 저장소의 Contents: Read and write)을 넣으면 그 기기 브라우저에만 저장됩니다.
- 필기본에서 편집한 내용은 같은 토큰으로 비공개 저장소에 자동 커밋되어 다른 기기에서도 보입니다.
- 필기본을 추가하려면 `index.html`의 `DOCS`에 항목을 넣고 `?doc=<키>`로 엽니다.
