필기본 뷰어

불러오는 중…

비공개 저장소 에 있는 필기본을 여는 페이지입니다. 이 기기에서 처음 열 때 한 번만 GitHub 토큰을 넣으면, 필기본과 편집 내용이 모두 불러와지고 편집하면 GitHub에 자동 저장됩니다.

  1. GitHub 토큰 만들기(Fine-grained token)
  2. Expiration은 넉넉하게(예: 1년) — 만료되면 새 토큰을 다시 넣어야 함
  3. Repository access → Only select repositories →
  4. Permissions → Repository permissions → Contents: Read and write
  5. 만들어진 토큰(github_pat_…)을 아래에 붙여 넣기

토큰은 이 기기의 브라우저에만 저장되고 GitHub 외의 곳으로는 보내지 않습니다. 나중에 필기본의 GitHub 동기화 창에서 연결을 해제할 수 있습니다.
